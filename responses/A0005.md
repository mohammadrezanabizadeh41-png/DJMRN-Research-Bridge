## 1. Decision brief

**Installed status has zero weight in technical merit.** Neither prior installation nor a few hours of possible setup was used to promote or reject a candidate in Stage I. Historical test evidence remains evidence only for its exact witnessed behavior. A familiar product receives no exemption from the common fixture.

Retain three alternative, not simultaneous, **conditional pilot finalists**:

- **QwenPaw2.2.2 with one local llama.cpp route:** integrated personal-assistant coverage, memory/files/scheduler/policy. Strongest broad ready-host research fit, but documented context recommendations, effective Windows policy and unattended behavior are material gates.
- **goose CLI1.55.0 with one local server:** headless recipe/workflow comparison, structured response settings and recent stop/session improvements. Its Electron Desktop is not compulsory. No low-total-RAM or deterministic security-classification claim.
- **Jan Agent CLI with an independently selected local server:** narrowly bounded read/plan comparison based on explicit deny/plan controls and documented fail-closed shell sandbox, **not installation**. Jan Desktop and the prior Jan4B model are not mandatory parts of this package.

These form a scenario frontier: integrated breadth, reusable headless workflow, restricted read-and-review. They are not a measured ordinal ranking. All full Persian/resource/security/recovery fixture results are **NOT RUN**. No candidate is cleared for unattended private work.

Independent adverse evidence changes the result:

1. **AnythingLLM Desktop is on eligibility HOLD under its separate app terms.** Its document strengths and 16GB recommendation are evaluated independently.
2. **PicoClaw's 10–20MB host claim excludes the complete local engine/model/browser workload.** Upstream pre-1.0 security warnings and explicit Windows isolation limitations prevent treating it as a proven safe lightweight winner.
3. **AionUi is a substantive agent product**, with verified original upstream/Electron UI/Rust backend and local model route. But applicable distributed-app terms and Windows permission/containment equivalence were not adequately resolved; keep it as a technical challenger, not automatically qualified.
4. A **Go1.27.2 demand-run worker** and **C#/.NET10 AOT worker** are serious native greenfield alternatives. Neither loses points for not being installed. They also cannot receive readiness points for unimplemented permission/retrieval/receipt promises.

No end-to-end, legally/account-qualified renewable-free cloud inference/search route for this Iran-based user was established. Hybrid variants remain research-only; local/manual operation must be useful independently.

### 5.1 Important network-boundary discriminator

Pinned QwenPaw security/config sources distinguish network open/block-all from domain control: domain-level filtering is not implemented; a domain allowlist may degrade to full-open or full-block depending on backend. Unelevated Windows restricted-token mode does not enforce network blocking against raw sockets. Therefore do not assume a URL allowlist in configuration confines arbitrary shell/MCP/skills. For the first fixture, deny these capabilities and use a separately trusted bounded fetch path; no instruction here grants admin execution, firewall changes or additional sandbox installation.

This principle applies to every package: an application-level approved-URL tool does not confine arbitrary code/plugin network access. If another path remains active, the boundary is not established. Disabling a model provider also does not sandbox plugin code.

## 6. Stage I — technical merit, with installation status excluded

### 6.1 Hard gates and rubric

First apply gates:
- **G-L legal/cost:** exact host/app/model/provider terms appropriate to intended use and region; renewable free route where external; unknown cost/eligibility denies that external/app route.
- **G-S bounded synthetic safety:** enforce selected paths/tools, no unauthorized write/exec/provider/channel/egress, no automatic approval for the first interactive fixture; revoke/deny works.
- **G-R admission:** current resource state and owned process tree observable; one model/job, bounded cancel/stop; no current headroom assumed from old snapshots.
- **G-E evidence:** raw source/version, valid quote, durable result and restart/readback, not a model assertion.

A gate marked U is a prerequisite for later testing, not an automatic approval. Passing a synthetic gate does not authorize private documents or website SEND. Known contrary contract text cannot be compensated by feature score.

For later comparisons, use five technical dimensions: F end-to-end coverage 25%; S safety/enforceability 25%; R whole-stack resource/foreground behavior 20%; Q Persian/structured output/provenance 20%; M maintainability/extensibility 10%. Cost/legal eligibility is a gate, not a compensable weight. Installation status, hours already spent, installer size and download convenience are **absent** from these weights.

Ordinal interpretation:
- 0: documented mismatch/absent or not implemented;
- 1: partial/manual/adaptation route;
- 2: documented mechanism with material fixture qualification outstanding;
- 3: complete matched fixture evidence.
Intervals are **epistemic possibilities, not benchmarks/confidence statistics**. Upper 3 is conditional on future evidence; no row has an observed 3. U=[0,3]. Do not choose midpoints or manufacture 0–100 rankings.
