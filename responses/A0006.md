## 3. Evidence vocabulary and common hard contract

- **PUBLISHER-DOCUMENTED:** official publication; not a device observation.
- **CODE-INSPECTED:** named tagged source read, not compiled/executed or a full security audit.
- **TESTED-HISTORICAL-SCOPE:** user-journal evidence within its literal old scope.
- **UNVERIFIED:** missing, moving, conflicting or not tied to the exact artifact.
- **CONTRACT HOLD:** eligibility/rights unresolved; no activation.
- **NOT RUN:** all proposed D0/fixture/benchmark/restart/security tests in this report.
- **ENGINEERING ASSUMPTION:** proposed design/bound/accounting, subject to explicit later acceptance.

A runnable candidate must expose only a trusted operation such as **read_source(source_id)** mapped by the controller to the single approved synthetic file. A model-provided arbitrary path, shell string, URL or output destination is not an acceptable substitute. Deny unknown IDs, traversal, absolute/UNC/device paths, alternate streams and reparse/symlink escape; do not use a string-prefix folder check as security. The controller must check the actual opened object against the approved manifest. Never create a real outside private file merely to test denial: the denied target is synthetic too, and denial must occur before reading.

Separate four layers:

| Layer | Can establish | Cannot establish alone |
|---|---|---|
| Model instruction | Intended behavior, handling of untrusted corpus | Filesystem, process or network enforcement |
| Host policy / tool inventory | Which invocation/arguments are exposed or denied | Isolation of arbitrary code or the entire app |
| Trusted fixed-operation controller | Exact file, schema, approval, digest and output destinations | Safety of an unaudited general host process outside that interface |
| Windows OS sandbox/ACL/token/network boundary | Actual enforced access for the covered process | Coverage of unrelated host-side tools, updater or child processes without verification |

The app may need private session/log writes to its own approved state directory. That is a separate disclosed installation/runtime effect, never permission to modify dossier or arbitrary user files. If the user requires literally zero disk writes by the host, these stateful agents need a different trial definition and are DEFERRED. Read-only task scope does not mean the application's entire process never writes.

No agent-level public or private network tools in the first offline fixture. Later inference loopback must be a fixed selected endpoint under controller policy, not arbitrary URL access. If stronger all-process isolation is required, a tool prompt alone cannot satisfy it. Unsupported enforcement means STOP, not administrator escalation or weakening the contract.

### 4.4 ONE triggered challenger: narrow Go worker

**Trigger:** QwenPaw's outside-root/global-read default and goose's Auto scheduled path demonstrably fail the required default contract; exact Jan nightly equivalence is unresolved. Evaluate only whether a narrow fixed-operation worker materially removes these gaps.

Proposed worker contract: immutable source-ID→preopened approved object mapping; no arbitrary filesystem API exposed to the model, no shell/subagent/plugin, no generic HTTP; optional fixed loopback inference; typed proposal returned to a human; exclusive-create/atomic single-result protocol with digest and job ID. This reduces exposed authority and avoids heuristic read/write classification. It is an **ENGINEERING ASSUMPTION**, not a product already installed or a completed deliverable.

Negative result: language choice alone does not establish Windows isolation, provenance, environment cleanliness, resource bounds, code correctness or durable storage. Go lexical [filepath.IsLocal](https://pkg.go.dev/path/filepath#IsLocal) does not account for symlinks. A safe worker would need real object/handle/reparse validation and review. A small host still pays the same model/KV/engine costs. No invented10MB all-in footprint or claim of superiority.

**Decision:** do not build this worker in Q6. P1 can use human-reviewed fixed files and no model. Only pursue this one challenger if a selected ready host cannot expose the fixed contract; no AionUi/OpenCode/Pico expansion in this report.

$ErrorActionPreference = 'Stop'
function Read-Q6 {
    param([scriptblock]$Read)
    try { & $Read } catch { [pscustomobject]@{ Status = 'UNAVAILABLE' } }
}
$Q6OS = Read-Q6 {
    $Q6o = Get-CimInstance Win32_OperatingSystem -Property Caption,Version,BuildNumber,OSArchitecture,TotalVisibleMemorySize,FreePhysicalMemory
    $Q6v = Get-ItemProperty -LiteralPath 'HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion'
    [pscustomobject]@{
        Edition = $Q6o.Caption
        Version = $Q6o.Version
        Build = $Q6o.BuildNumber
        UBR = $Q6v.UBR
        DisplayVersion = $Q6v.DisplayVersion
        Architecture = $Q6o.OSArchitecture
        VisibleGiB = [math]::Round($Q6o.TotalVisibleMemorySize / 1MB, 3)
        AvailableGiB = [math]::Round($Q6o.FreePhysicalMemory / 1MB, 3)
    }
}
$Q6Commit = Read-Q6 {
    $Q6m = Get-CimInstance Win32_PerfFormattedData_PerfOS_Memory -Property CommittedBytes,CommitLimit,AvailableMBytes
    [pscustomobject]@{
        CommittedGiB = [math]::Round($Q6m.CommittedBytes / 1GB, 3)
        CommitLimitGiB = [math]::Round($Q6m.CommitLimit / 1GB, 3)
        CommitHeadroomGiB = [math]::Round(($Q6m.CommitLimit - $Q6m.CommittedBytes) / 1GB, 3)
        AvailableMiB = $Q6m.AvailableMBytes
    }
}
$Q6Pagefile = Read-Q6 {
    $Q6c = Get-CimInstance Win32_ComputerSystem -Property AutomaticManagedPagefile
    $Q6p = @(Get-CimInstance Win32_PageFileUsage -Property AllocatedBaseSize,CurrentUsage,PeakUsage)
    [pscustomobject]@{
        AutomaticManagedPagefile = $Q6c.AutomaticManagedPagefile
        AllocatedMiB = ($Q6p | Measure-Object AllocatedBaseSize -Sum).Sum
        CurrentUsedMiB = ($Q6p | Measure-Object CurrentUsage -Sum).Sum
        PeakUsedMiB = ($Q6p | Measure-Object PeakUsage -Sum).Sum
    }
}
$Q6Processes = Read-Q6 {
    $Q6names = @('jan','goose','qwenpaw','python','pythonw','llama-server','llama-cli','ollama','LM Studio','chrome','msedge','msedgewebview2')
    @(Get-Process | Where-Object { $Q6names -contains $_.ProcessName } |
      Group-Object ProcessName | ForEach-Object {
        [pscustomobject]@{
            App = $_.Name
            Count = $_.Count
            WorkingSetMiB = [math]::Round(($_.Group | Measure-Object WorkingSet64 -Sum).Sum / 1MB, 1)
            PrivateMiB = [math]::Round(($_.Group | Measure-Object PrivateMemorySize64 -Sum).Sum / 1MB, 1)
        }
    })
}
[pscustomobject]@{
    Schema = 'Q6-D0-v1'
    UTC = (Get-Date).ToUniversalTime().ToString('o')

    Commit = $Q6Commit
    Pagefile = $Q6Pagefile

} | ConvertTo-Json -Depth 6
